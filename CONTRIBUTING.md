# Contributing

Issues and pull requests are welcome. Good first areas are in [CHECKLIST.md](CHECKLIST.md) under "Faked or limited" and "Still missing", for example live price adapters for more providers.

Keep changes small, add a test, and run `npm test` in `backend/` before you open a PR. The scanner must stay passive: it only reads what any visitor can see, unless the owner has proven the site is theirs.
